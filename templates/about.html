About the project

A complete classification system—not five disconnected demos.

PulseVector demonstrates how to turn a small supervised-learning dataset into a reproducible, tested, deployable FastAPI application with transparent model selection.

Problem framing

Educational binary classification

The system predicts whether the model assigns a record to heart disease present or not detected. It does not diagnose a person and does not provide treatment or clinical decision support.

Required disclaimer

Not a medical diagnostic tool.

Architecture

Clear responsibilities across the stack

ML layer

Leakage-safe preprocessing, five candidate pipelines, shared stratified folds, winner selection, and artifact generation.

Service layer

Cached model loading, safe report access, prediction orchestration, and honest readiness checks.

Web layer

FastAPI routes, Pydantic validation, Jinja2 pages, accessible HTML, responsive CSS, and vanilla JavaScript.

Quality layer

Pytest, coverage enforcement, independent metric verification, CI pipeline, and failure-mode simulation.

Methodology

Selection before test evaluation

  1. 01
    Define features and binary target

    Document source values and preserve exact feature order.

  2. 02
    Create one stratified split

    Hold out 20% of rows and keep them isolated from selection.

  3. 03
    Compare five pipelines

    Use the same five materialized StratifiedKFold splits.

  4. 04
    Lock the CV winner

    Highest F1, then recall, then accuracy.

  5. 05
    Evaluate and verify

    Report held-out results once and independently recompute them from saved predictions.

Known limitations

What this project does not claim

Small historical dataset

The Cleveland data contains 303 records and may not represent modern or broader populations.

Educational probability

The displayed probability is a model estimate, not certainty, diagnosis, or individualized risk advice.

No clinical validation

The application has not been prospectively validated, certified, or reviewed for healthcare use.
